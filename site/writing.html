새 글감 후보

브랜딩/캐릭터, 문서 챗봇, UT, 웹 디자인-개발 test는 Notion 원본이 연결되어 있어 바로 확장하기 좋습니다.

순서 글감 추천 형태 메모
1 AI로 브랜딩 구축 프로세스 단독 글 또는 사례 연재 쏘냥이 원본 문서 4개가 연결되어 있어 캐릭터/컬러/말투/모션 기준으로 확장 가능
2 AI로 캐릭터/모션 생성 프로세스 단독 글 또는 case 이미지 생성, 모션 생성, UI 삽입 전 검수, 개발 전달 포맷까지 사례화 가능
3 문서 기반 Q&A / 챗봇 wiki playbook + 글 Notion, wiki, worklog를 source map으로 묶고 챗봇이 답할 수 있는 경계를 정리
4 제품 단계 진단 테스트 간단 테스트 / 체크리스트 OBT, MVP, Sprint, live 단계에 따라 디자인/실험/데이터 기준을 다르게 추천
5 UT나 데이터 기반 판단 기준 단독 글 또는 guide 설문 + 콜인터뷰 PD 논의를 바탕으로 AI 제품 UT 질문 구조를 글로 전환
6 AI로 웹사이트 디자인-개발 프로세스 줄이기 case 또는 비교 글 Figma Make, Framer, Cursor를 팀 구성과 유지보수 기준으로 비교
7 코드 <-> 피그마 양방향 연동 결과 기록 case Figma evidence package, source of truth, sync 성공/실패 기준으로 묶기

Notion 원본 연결

원본 전체를 복사하지 않고, 글감으로 쓰기 좋은 포인트만 연결했습니다.

쏘냥이 만들기 26년ver 쏘냥이 이미지/모션 제작 가이드 브랜딩, 캐릭터/모션, 리소스 운영 글감 멀티 모델 UI 멀티모델 서비스 UI 레퍼런스와 인사이트 모델 선택 UX, model routing, 생산성 도구 확장 유저 설문 + 콜인터뷰 PD논의 설문/인터뷰 질문 설계 UT, 데이터 기반 판단, 제품 단계 진단 웹사이트 디자인-개발 test Figma Make, Framer, Cursor 테스트 AI 디자인-개발 툴 선택 기준 쏘냥이 일관성 유지용 프롬프트 마스터 프롬프트와 가변 슬롯 캐릭터 일관성, 이미지/텍스트 학습 비교 소크라 튜터 프로덕트 디자인 상위 디자인 문서 허브 후속 DB 인벤토리, 제품 단계별 글감 발굴
