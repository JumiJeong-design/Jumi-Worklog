# 02. 스토리북에서 화면을 조합할 때 개별 컴포넌트 코드를 안 쓰던 이유

상태: ✅ 완료 · 기간: 2026-06 ~ 2026-08

## 문제 정의 / 도입 배경

스토리북에 화면(페이지) 스토리를 올리기 시작했을 때, 에이전트가 화면을 조합하면서 패키지에 있는 컴포넌트를 import하지 않고 손으로 비슷한 마크업을 그리거나 자리표시 상자를 넣었다. 겉보기엔 화면이 나오는데, 그 화면은 패키지와 아무 관계가 없었다. 패키지 컴포넌트를 고쳐도 화면 스토리는 안 바뀌고, 화면 스토리에서 본 것이 제품과 같다는 보장이 없었다.

이 상태에서는 스토리북이 검수 표면이 아니라 그림판이다.

## 목표

- [x] 화면 스토리가 패키지 컴포넌트만으로 조합되게 한다
- [x] 자리표시와 더미 에셋을 스토리에서 없앤다
- [x] 왜 그렇게 되는지를 규칙으로 남긴다

## 사용한 툴

- Claude Code · 프리즘 패키지 · 스토리북 · 피그마 에셋

## 작업 과정

### 1단계. 왜 안 쓰나를 먼저 봤다

에이전트가 컴포넌트 코드를 안 쓰는 이유는 셋이었다.

- 패키지 컴포넌트의 공개 속성이 화면이 원하는 배치와 안 맞을 때 감싸서 쓰는 대신 새로 그린다.
- 피그마에 있는 에셋(아이콘·이미지)을 가져오는 경로가 없으면 회색 상자를 넣는다.
- 「일단 느낌만 보자」는 요청을 받으면 완성본을 빨리 내려고 지름길을 탄다.

### 2단계. 규칙 셋으로 막았다

```
데모에 자리표시 넣지 마. 피그마 에셋 써.
```

```
페이지 스토리는 실제 컴포넌트로 만들어. Socra 화면은 Socra 컴포넌트만.
```

- 「데모에 자리표시 금지」와 「페이지 스토리는 실제 컴포넌트로」를 프로젝트 규칙으로 적었다.
- 피그마에 없는 컴포넌트가 필요하면 스토리북에 먼저 만들지 않고 피그마 생성·승인으로 분리했다. 정본 순서가 피그마 > 패키지 > 스토리북이라서다.

### 3단계. 안 맞는 자리는 감싸서 풀었다

- 패키지 컴포넌트가 `w-full`을 박고 있어 className으로 폭을 못 줄이는 경우가 있었다. 컴포넌트를 복제하지 않고 감싸는 요소로 폭을 잡았다.
- 글래스 크롬 안에 든 Toast는 backdrop-filter가 죽었다. 컴포넌트를 새로 그리는 대신 popover와 anchor positioning으로 층을 바꿨다.

## 트러블슈팅

**문제 1**: 화면 스토리가 패키지 변경을 안 따라온다
- 원인: 스토리가 컴포넌트를 import하지 않고 마크업을 복제했다.
- 해결: 규칙으로 막고, 스토리 전수 감사(plan-35)에서 자리표시·손마크업 스토리를 찾아 실제 컴포넌트로 바꿨다. 눈대중 삭제는 금지하고 소비처를 세서 판정했다.

**문제 2**: 「느낌만 볼」 단계에 상태 전수 45개를 만들려 했다
- 원인: 확정 단계의 목록을 탐색 단계에 들이댔다.
- 해결: 탐색 단계엔 대표 컷 한 장, 배치 축 서너 개만. 완성본이 빨리 나오면 사고가 좁아진다.

## 결과

- 화면 스토리가 패키지 컴포넌트로만 조합된다. 패키지가 제품 레포에 들어간 뒤(제품 src 55개 파일이 패키지를 문다) 스토리북이 곧 제품 중간 뷰가 됐다.
- 스토리북 IA의 목적이 「제품에 올라가는 중간 뷰」로 정리됐다.

## AI가 잘한 것 / 디자이너가 보정한 것

- AI: 스토리 전수를 세고, 자리표시가 남은 자리를 찾고, 감싸는 방식으로 폭 문제를 푼 것.
- 디자이너: 「자리표시 말고 피그마 에셋」이라는 선을 그은 것. 어느 화면이 제품에 올라가는 중간 뷰인지 정한 것.

## 아쉬운 점 · 리스크

- 규칙은 적어도 새 세션이 다시 지름길을 탄다. 감사(plan-35)로 뒤에서 잡는 비용이 남는다.
- 패키지에 칸이 없는 배치는 감싸서 풀지만, 그게 쌓이면 화면 쪽에 사설 레이아웃이 늘어난다.

## 공유할 만한 사항

```
페이지 스토리는 패키지 컴포넌트만 import해서 조합해. 손으로 그리거나 자리표시 넣지 마.
패키지에 없는 컴포넌트가 필요하면 만들지 말고 「피그마에 없다」로 보고해.
```

## 한 줄 평

스토리북이 그림판이 되는 순간 검수 표면이 아니게 된다. 막는 건 규칙 두 줄이고, 지키게 하는 건 정본 순서다.
