# 17. 44px 히트 타깃 겹침은 양쪽을 다 넓혀서 잰다

상태: ✅ 완료 · 기간: 2026-08 ~ 09

## 문제 정의 / 도입 배경

터치 영역 44×44 규칙을 넣었더니 인접 요소끼리 히트 타깃이 겹치는 자리가 생겼다. 겹침을 세는 방법이 틀리면 없는 문제를 만들거나 있는 문제를 놓친다.

## 목표

- [x] 겹침을 재는 방법을 정한다
- [x] 규칙 도입 전부터 겹치던 짝을 뺀다

## 사용한 툴

- Claude Code · 헤드리스 렌더 · origin/main 베이스라인

## 작업 과정

- 한쪽만 넓혀서 재면 반쪽이다. 양쪽 다 44로 넓혀서 잰다.
- 넓히기 전에 이미 겹치던 짝은 뺀다. origin/main 베이스라인과 차집합으로 「이번에 새로 생긴 겹침」만 남긴다.
- 「간격 0」은 대개 가로 이야기다. 세로 겹침은 따로 본다.
- 대표 자리 하나만 재면 나머지가 깨진 채 통과한다. 앵커·부모 display가 여럿이면 전부 잰다. grid 셀에서 `width: auto`는 늘어난다.

## 트러블슈팅

**문제**: 수치 표가 다 통과했는데 컷이 이상했다
- 원인: 표는 잰 자리만 말한다.
- 해결: 수치 표가 다 통과해도 컷을 한 장 본다.

## 결과

- 겹침 측정 규칙: 양쪽 확장 · 베이스라인 차집합 · 자리 전수 · 컷 한 장.
