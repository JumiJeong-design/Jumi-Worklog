# 16. Quick 카드 「카드가 크다」의 원인은 제목이 아니라 라벨이었다

상태: ✅ 완료 · 기간: 2026-09

## 문제 정의 / 도입 배경

Quick 결과 카드가 커 보인다는 지적. 제목 크기를 줄이자는 쪽으로 갈 뻔했는데, 재 보니 제목이 아니라 라벨이었다.

## 목표

- [x] 무엇이 커 보이게 하는지 가른다
- [x] 글자 계단을 정한다

## 사용한 툴

- Claude Code · 스토리북 · 피그마

## 작업 과정

- 제목 24, 라벨 17이었다. 라벨이 제목과 너무 가까워서 계단이 없었고, 그래서 카드가 통째로 커 보였다.
- 라벨을 15로 내렸다. 제목 24 / 라벨 15. 바뀌는 건 높이가 아니라 밀도다.

## 트러블슈팅

**문제**: 「크다」를 높이로 읽었다
- 원인: 지적의 단어를 그대로 수치로 옮겼다.
- 해결: 지적은 감각이고 원인은 따로 잰다. 여기서는 밀도였다.

## 결과

- 제목 24 / 라벨 15 계단. 카드 높이는 거의 그대로인데 「크다」가 사라졌다.

## AI가 잘한 것 / 디자이너가 보정한 것

- AI: 제목·라벨 조합을 나란히 렌더한 것.
- 디자이너: 「높이가 아니라 밀도」라고 본 것.

## 한 줄 평

「크다」는 말은 높이 얘기가 아닐 수 있다. 계단이 없으면 커 보인다.
