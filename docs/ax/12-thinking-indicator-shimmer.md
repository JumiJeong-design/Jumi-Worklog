# 12. 답변 대기 인디케이터 — 3닷에서 시머 텍스트로

상태: ✅ 완료 · 기간: 2026-09-05 전후

## 문제 정의 / 도입 배경

답변 대기 상태에 3닷 로딩이 있었는데 정지 프레임만 정의돼 있었다. 움직임이 없으니 「기다리는 중」이 안 읽혔고, 질문에서 답변까지의 흐름에서 어디에 무엇이 뜨는지도 정해져 있지 않았다.

## 목표

- [x] 대기 표현을 정한다
- [x] 수치를 정한다
- [x] 흐름 스토리로 검수한다

## 사용한 툴

- Claude Code · 스토리북 흐름 스토리 · 프리즘 토큰(gradient.brand-fill)

## 작업 과정

- 후보 넷 중 시머 텍스트 D로 갔다. 정지 컷으로는 못 고르고, 움직이는 걸 나란히 보고 골랐다.
- 폭은 문장 폭의 55%(mask-size 220% 환산). 2400ms 호흡 계열.
- 새 색을 만들지 않고 gradient.brand-fill을 마스크로 썼다. 토큰 신설 없이 브랜드 값이 바뀌면 같이 바뀐다.
- 흐름은 「Chat 답변 대기 — 질문에서 답변까지」 스토리(PR #583)에 넣었다.

## 트러블슈팅

**문제**: 흐름 스토리가 고정 폭이라 리사이즈를 안 탄다
- 원인: 폭이 안 바뀌는 스토리는 고쳐도 안 고쳐도 같은 값이 나온다.
- 해결: 폭 반응은 폭이 실제로 바뀌는 스토리로 잰다.

## 결과

- 대기 표현이 시머 텍스트로 확정되고 수치가 상수로 내려갔다.

## AI가 잘한 것 / 디자이너가 보정한 것

- AI: 후보를 컨트롤로 띄우고 mask-size 환산을 한 것.
- 디자이너: D를 고른 것. 새 색 대신 브랜드 그라디언트를 쓰라고 한 것.

## 아쉬운 점 · 리스크

- reduced-motion에서 시머가 사라지면 「대기 중」 정보도 사라진다.
