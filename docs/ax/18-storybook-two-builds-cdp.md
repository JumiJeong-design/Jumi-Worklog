# 18. 스토리북 게시본 두 빌드를 CDP로 대조하기

상태: ✅ 완료 · 기간: 2026-08

## 문제 정의 / 도입 배경

배포 전에 무엇이 바뀌는지 보고 싶은데 시각 스냅샷 비교가 막혀 있었다. 게시본 URL은 둘 다 있었다.

## 목표

- [x] 스냅샷 도구 없이 두 빌드를 대조한다
- [x] 기준점을 잘못 잡는 함정을 피한다

## 사용한 툴

- Claude Code · CDP 헤드리스 · 스토리북 게시본 두 URL

## 작업 과정

- URL 두 개면 된다. 같은 스토리를 두 빌드에서 열어 픽셀을 비교한다.
- `load`를 기준점으로 쓰면 스피너끼리 비교한다. 렌더 완료를 따로 기다린다.
- 0%도 못 믿는다. 둘 다 빈 화면이면 0%다. 잉크 비율(밝기 225 미만)로 「내용이 있나」를 같이 잰다. 상자를 키우면 rect 덮임은 오르고 내용은 그대로라 덮임으로 재면 반대로 나온다.
- 정적 서버 포트가 이미 점유돼 있으면 옆 세션 빌드를 잰다. `http.server`가 조용히 죽는다. 파일이 아니라 서버가 주는 `index.json`으로 판정하고, 점유 프로세스는 죽이지 말고 포트를 옮긴다.

## 트러블슈팅

**문제**: 헤드리스에서 한글 textContent 매칭이 실패했다
- 원인: NFC/NFD 정규화 차이.
- 해결: 텍스트 말고 구조로 찾는다.

## 결과

- 스냅샷 없이 두 빌드 대조가 가능해졌다. 기준점·잉크·포트 세 함정을 규칙으로 남겼다.
