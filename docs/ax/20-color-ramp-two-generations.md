# 20. 색 램프가 두 세대로 살고 이름이 한 칸 밀려 있었다

상태: ✅ 완료 · 기간: 2026-08 ~ 09

## 문제 정의 / 도입 배경

피그마와 코드의 회색이 이름은 같은데 값이 달랐다. 이름으로 대조하면 맞아 보이고 값으로 대조하면 틀렸다. 같은 사고가 두 번 났다.

## 목표

- [x] 이름과 값 중 무엇으로 대조할지 정한다
- [x] 두 세대가 왜 생겼는지 가른다

## 사용한 툴

- Claude Code · Figma 변수 컬렉션 · 코드 토큰 파일

## 작업 과정

- 피그마와 코드의 회색 이름이 한 칸 밀려 있었다. 값으로 대조해야 맞는다.
- 소비 파일에 색 변수가 두 세대로 살고 있었다. 이름은 같은데 다크 값만 다르다. 라이트가 같아 안 보인다.
- 코드의 다크 회색 램프가 옛 세대였다. 이름 오프셋이 아니라 세대 차이다. alias는 따라와도 손으로 박은 rgba는 안 따라온다.
- 색 램프 80칸엔 다크 값이 이미 다 있었다. 코드가 4칸만 가져왔다. 계약과 plan은 「다크 값 없음」으로 반대로 적혀 있었다.

## 트러블슈팅

**문제**: 문서를 믿고 「다크 값이 없다」고 판단했다
- 원인: 계약·plan이 낡아 있었다.
- 해결: 정합 판정은 피그마 변수와 마스터를 직접 재서 한다. 레포 문서와 다르면 문서가 낡은 것으로 보고 그 줄도 적는다.

## 결과

- 대조는 값으로. 두 세대 문제와 문서 반대 기술을 메모리와 문구에 남겼다.

## AI가 잘한 것 / 디자이너가 보정한 것

- AI: 80칸을 값으로 대조해 4칸만 가져온 것을 찾은 것.
- 디자이너: 「이름이 같은데 왜 다르냐」를 되물은 것.

## 한 줄 평

이름은 같아도 값은 다를 수 있다. 문서는 마스터보다 낡는다.
