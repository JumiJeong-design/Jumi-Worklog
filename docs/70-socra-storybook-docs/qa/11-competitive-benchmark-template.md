# 11. Competitive Benchmark Template

## 1. 목적

Socra AI의 UX/UI 완성도를 경쟁 서비스와 비교하기 위한 벤치마크 템플릿이다.

비교의 목적은 단순히 따라 하는 것이 아니라, Socra의 차별점과 부족한 완성도 지점을 찾는 것이다.

---

## 2. 비교 대상

| 서비스 | 비교 이유 |
|---|---|
| ChatGPT | 기본 AI 채팅 UX 기준 |
| Claude | 긴 답변 가독성 / 문서형 답변 |
| Perplexity | 출처 / citation / research UX |
| Poe | 여러 모델 선택 / 모델 구분 |
| Gemini | Google 생태계 AI UX |
| Notion AI | 문서형 AI 답변 / 요약 |
| Elicit / Consensus | 연구/근거 기반 답변 UX |
| Linear / Raycast | SaaS UI polish / keyboard UX |

---

## 3. 비교 항목

| 항목 | 질문 | Socra 점수 | 참고 서비스 |
|---|---|---:|---|
| 답변 가독성 | 긴 답변이 읽기 쉬운가 |  |  |
| 모델/에이전트 구분 | 답변 주체가 명확한가 |  |  |
| 비교 UX | 여러 답변의 차이가 잘 보이는가 |  |  |
| 종합 요약 | 최종 판단이 명확한가 |  |  |
| 출처 UX | 출처를 신뢰할 수 있게 보여주는가 |  |  |
| 차트 UX | 수치/점수/비교가 잘 이해되는가 |  |  |
| 모바일 UX | 좁은 화면에서 핵심이 먼저 보이는가 |  |  |
| 다크모드 | 색/대비/surface가 안정적인가 |  |  |
| 모션/인터랙션 | 상태 변화가 자연스럽고 예쁜가 |  |  |
| 빈/에러 상태 | 실패했을 때 회복 가능성이 보이는가 |  |  |
