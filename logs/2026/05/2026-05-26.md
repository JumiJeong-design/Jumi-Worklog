### 함정 모음

- **Pencil MCP 내부 변수 참조** — `.pen` 파일에 자체 변수 시스템(`$--primary`, `$--accent`)이 이미 세팅되어 있어 HTML/CSS 토큰을 넘겨도 Pencil이 자기 팔레트로 렌더링한다. 디자인 시스템 싱크가 필요하면 변수를 덮어써야 한다.
- **Figma OAuth 상태 유지 실패** — `figma-pat` MCP 서버가 원격 HTTP 서버라 `authenticate` 호출 후 사용자 응답 대기 중 로컬 임시 서버가 닫혀 `complete_authentication` 시 "No OAuth session" 에러가 발생했다. Claude Code 재시작으로 해결했다.
- **Notion 동기화 전체 실행** — 인자 없이 `sync-devlog-to-notion.mjs`를 실행하면 전체 devlog 파일을 처리해 중복 생성된다. 오늘 날짜 파일만 처리하도록 기본값을 수정했다.

### 회고 및 인사이트

### 도구 선택

- **Pencil vs Figma** — 팀 협업, 핸드오프, 디자인 시스템 관리 목적이라면 Figma가 맞다. Pencil은 혼자 빠르게 스케치할 때만 유효하다.
- **Figma OAuth 불안정** — PAT(Personal Access Token) 방식 전환을 검토해야 한다. OAuth는 재시작마다 재인증이 필요한 구조적 문제가 있다.

### 워크플로우 인사이트

- **코드가 소스 오브 트루스가 되면 탐색 단계가 사라진다.** 코드는 결정된 것을 구현하는 도구이지 탐색 도구가 아니다. 브랜딩과 스타일 결정은 코드 진입 전에 별도 탐색 단계가 필요하다.
- **문서 구조는 단일 진실 공급원이 있어야 한다.** `DESIGN-SC.md`와 `DESIGN_SYSTEM.md`가 분리되어 있으면 어느 문서가 최신인지 불분명해진다.
