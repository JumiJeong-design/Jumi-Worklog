### 함정 모음

- **미게시 컴포넌트는 import 불가** — DS에 새로 만든 컴포넌트는 라이브러리 게시 전엔 제품 파일에서 `importComponentByKeyAsync`가 실패한다. 신설→게시→제품 치환 순서를 계획에 미리 넣을 것.
- **라이브러리 아이콘 재인스턴스화 시 검정 fill 부활** — 제품 화면의 lucide 아이콘이 깨끗해 보여도 그건 인스턴스 override(fill 제거) 덕분. DS에서 새로 인스턴스를 뜨면 마스터의 검정 fill이 살아난다. 같은 fill 제거 override를 다시 걸어야 정합.
- **"스펙이 없다"고 단정하기 전에 탐색 프레임부터** — 시트 피드백 선택 상태가 없다고 보고했는데 `피드백 · 도움 됐어요 선택` 프레임에 이미 있었다(Button `State=engaged`). 상태 스펙은 상태명 프레임 검색 먼저.
- **"전수 스캔" 오보 — 페인트 타입 커버리지 명시** — 색 감사에서 SOLID만 보고 "미바인딩 소진"이라 단정했다가 Deep 그라데이션·그림자 누락을 주미님이 지적. 전수라 말하려면 SOLID+GRADIENT 스톱+EFFECT 색을 다 돌리고 보고에 범위를 명시할 것.
- **인스턴스 swap은 텍스트 오버라이드를 초기화한다** — Attachment 치환 때 에러 칩 문구("5페이지 초과" 등)가 기본값으로 덮였다. swap 전 텍스트 스냅샷→swap→복원 + 전후 스크린샷 대조를 게이트로. 오후 chat/chart 치환은 이 절차로 4건 보존.
- **변수는 컬렉션 이름만 보고 못 찾는다** — 13px이 `font-size` 컬렉션엔 없어 "스케일 부재"로 판단했는데 `typography` 컬렉션 `font/size/13`에 있었다. 값 검색은 전 컬렉션 FLOAT 전수로.

### 회고 및 인사이트

#### AI 도구 활용

- 페이지 전수 스캔(텍스트 패턴 + 프레임 이름)으로 손코딩 33곳을 한 번에 잡고 4개 배치 스크립트로 일괄 치환 — 화면 단위로 하나씩 여는 것보다 검증(스크린샷 2장 육안)까지 포함해 수 분 안에 종료.

#### 설계 결정

- **피드백 선택 문법 통일** — engaged = 면 `neutral/100` + 안쪽 1px 선. 선 강도는 주미님이 `neutral/300`으로 직접 튜닝해 확정. `Report/Feedback`·`Button/ActionBar`·`Answer/Feedback` 3곳 공유.
- **`Answer/Feedback`은 별도 컴포넌트** — 리포트 피드백(👍👎 아이콘 칩)과 UI 문법이 달라(텍스트 라벨 outline Button 2개) 한 세트에 축으로 우겨넣지 않음.
- **추론 텍스트는 Message Bubble 아님**(주미님 판정) — "답변을 요약해서 리포트를 만들었다!"류는 현행 유지.
- **행간 촘촘 계층 = 140% 확정**(주미님) — 130%는 멀티라인·JP 글리프 클리핑 위험. `body/xs-r-tight`·`body/sm-m-tight`·`caption/2-tight` 신설.
- **Deep 링 색은 램프 편입 아닌 브랜드 그룹** — `#4DD959`·`#3D80FF`는 green/blue 램프 어디에도 없는 링 전용 값이라 `brand/deep-ring/*`으로 신설(램프에 끼우면 이름이 거짓말).
- **브랜드색 토큰 신설 기준 = 재사용**(주미님 "과해") — 카카오/라인 로그인 색은 로그인 화면 한정이라 하드코딩 동결, add-as-earned. 그림자 스냅은 정확 일치분만.
