### 회고 및 인사이트

#### AI 도구 활용

- **코드 리뷰가 잡은 것과 못 잡은 것이 갈렸다.** 리뷰는 코드 안의 결함(제스처 처리·포커스·전역 CSS 범위)을 정확히 짚었지만, **정본과의 어긋남 둘은 못 잡았다** — 실행 버튼이 `disabled`가 아니라 `State=loading`이어야 한다는 것, `locked`에서도 명시적 닫기는 남는다는 것. 둘 다 피그마 컷을 열어야 나오는 것이고 리뷰는 레포 안만 본다. **리뷰를 돌렸다고 정본 대조를 건너뛰면 안 된다.**
- **헤드리스 Chrome + 스토리북 정적 빌드로 시각 판정이 된다.** `python3 -m http.server`로 띄우고 `--headless --screenshot`으로 스토리 iframe을 찍으면 잠긴 버튼·포커스 링 같은 상태가 실제로 그려진 채 잡힌다. 다만 **대조군을 내 구현끼리 세우면 「다르다」까지만 나온다** — 정본 컷을 `get_screenshot`으로 함께 받아 나란히 봐야 어긋남이 드러난다.

#### 설계 결정

- **오버레이 닫기 등급을 플랫폼이 아니라 「닫히면 뭘 잃나」로 갈랐다.** 발단은 「모바일은 dim으로 닫히고 웹은 안 닫히게」였는데, iOS·Material·웹 접근성 기준 전부 플랫폼이 아니라 오버레이 안에 든 것으로 가른다. 기기로 가르면 같은 로그인 모달이 폰에서만 실수로 날아가 사용자가 규칙을 배울 수 없다.
- **등급 이름을 HTML `<dialog closedby>` 표준 값에서 가져왔다**(`any`·`closerequest`·`none` → `light`·`guarded`·`locked`). 이름 짓기 논쟁이 없어지고, Safari까지 지원되면 손으로 만든 판정이 속성 한 줄로 줄어든다. 지금은 Chrome·Firefox·Edge만 지원한다.
- **`locked`가 막는 것은 「저절로 닫히는 경로」로 정리했다.** 스크림·닫기 요청·스와이프는 막고 취소·닫기 버튼은 남긴다. 「요청이 나간 뒤 취소를 누르면 처리됐는지 모른다」는 우려는 버튼을 잠가도 해결되지 않는다 — 진짜 해결은 요청 자체를 취소하는 것이다.

## 오버레이 닫기 경로에 등급을 세우고 바텀시트 스와이프를 구현했다 (8/31 밤 ~ 9/1)

발단은 이 물음이었다.

```
모달에 대한 규칙 정의가 지금 없는거같아
모바일에선 dim 누르면 나가고, 웹에서는 안나가고, 이런식으로? 근데이게 제네럴한가?
```

**규칙은 실제로 없었다.** 계약 셋이 각자 「스크림 클릭·ESC·닫기 버튼에서 `onClose`」라고 적어 놨을 뿐, 언제 스크림으로 닫아도 되는지를 가르는 기준이 어디에도 없어서 셋 다 똑같이 닫혔다 — 로그인 폼을 담은 `ModalShell`도, 서버 응답을 기다리는 동안에도.

**플랫폼으로 가르는 것은 관습이 아니었다.** iOS·Material·웹 접근성 기준 전부 오버레이 안에 든 것으로 가른다. 다만 플랫폼이 영향을 주는 자리가 하나 있다 — 닫기 요청(Esc)은 데스크톱 키보드와 안드로이드 뒤로가기에만 대응하고 **iOS Safari에는 대응 동작이 없다.** 그래서 스크림을 막으면 iOS에서는 보이는 버튼만 남는다.

### 리뷰 반영과 정본 대조

리뷰 15건 중 실제 버그는 전부 스와이프에 몰려 있었다. 제스처를 ref로 들고 손가락 식별자로 추적하게 고쳤다. 그 밖에 `dialog { outline: none }`을 공개 CSS에 넣었다가 세 컴포넌트로 좁혔고(그 파일 주석이 「소비처 dialog에도 걸린다」고 경고하는데 읽고도 넣었다), 잠글 때 포커스가 `body`로 떨어져 안 돌아오던 것도 고쳤다.

**잘못 적은 문서 셋도 리뷰가 짚었다** — `aria-busy`는 알림이 아니라 억제 힌트이고, 라이트박스 세로 스와이프가 없는 이유는 「좌우와 겹쳐서」가 아니라 8/7 「굳이」 폐기이며, `locked`의 중복 실행 방지는 `ModalDialog`에서만 참이다(나머지 둘은 본문이 슬롯이라 안쪽이 그대로 눌린다).

**정본 대조에서 둘 더 나왔다.** 실행 버튼은 `disabled`가 아니라 `State=loading`이고(`11633:7433`), `locked`에서도 명시적 닫기는 남는다. 둘 다 주미님이 되물어서 드러났다.
