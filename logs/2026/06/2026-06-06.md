### 함정 모음

- **Chromatic 원격 환경 IP 차단** — Claude Code 원격 컨테이너 IP가 Chromatic에서 401/403 반환. GitHub Actions CI에서 실행하는 방식으로 우회. `CHROMATIC_PROJECT_TOKEN` secret은 GitHub repo 설정에서 관리.
- **`pnpm/action-setup@v4` + `version:` 충돌** — `packageManager: pnpm@11.3.0`이 package.json에 있으면 `version:` 필드가 충돌. `version:` 제거하면 자동 감지.
- **MDX markdown pipe tables 미렌더링** — MDX 3은 `remark-gfm` 없이 GFM 파이프 테이블을 처리하지 않음. HTML `<table>` 직접 작성으로 해결.
- **Storybook docs 다크모드 Canvas 배경 흰색** — `withTheme` decorator는 story 렌더 안에서만 실행됨. docs page shell에는 `dark` class가 안 붙음. `addons.getChannel()`로 `setGlobals` / `globalsUpdated` 이벤트를 module-level에서 구독해 해결.

### 회고 및 인사이트

#### AI 도구 활용

- Storybook docs 페이지는 decorator 범위 밖 — docs shell에 theme class 적용은 channel listener를 module-level에서 등록해야 함. story 단위 decorator만으로는 불충분.
- MDX + Storybook 10에서 HTML 테이블이 안전. `remark-gfm` 없이는 파이프 테이블 미지원.
- Chromatic 원격 환경 차단은 GitHub Actions 패턴으로 우회 — CI 환경에서 실행이 신뢰도도 더 높음.

#### 설계 결정

- component docs는 Figma guide card → Storybook MDX로 전환. Button 먼저 시범, 나머지 12개 동시 적용.
- 개별 stories (Default, Matrix, Interactive)는 Docs 페이지와 다른 목적 — Chromatic 스냅샷·play() 테스트 용이므로 유지.
- Chromatic CI는 `claude/**` 브랜치 포함, push 시 자동 실행.
