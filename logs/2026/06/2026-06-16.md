## Decisions

- Glass 파라미터 표준: `tone=ios` + `displace={6}` + `backgroundOpacity={0.3}` — ios tone으로 담백하되 displace로 backdrop blur 추가, opacity로 배경 반투명
- `light-dark()` CSS 함수는 color-scheme 속성 기준으로 동작. .dark 클래스만으로는 부족 → styles.css에 color-scheme 선언 추가 필요
- Storybook applyTheme에서 light 선택 시 .light 클래스 명시 추가 필요 (기본값이 dark이므로)

## Attempts / Traps

- **GlassSurface className vs contentClassName 혼동** — `className`은 outer container에 적용됨. flex 레이아웃은 반드시 `contentClassName`에 넣어야 함
- **ios tone = 블러 없음 아님** — ios tone은 chromatic aberration만 줄이는 것. 블러는 `displace` prop(feGaussianBlur stdDeviation)으로 별도 설정 필요. 기본값 0이라 빠지면 블러가 아예 없음
- **Checkbox size prop 누락** — PrismIcon은 size prop 기준으로 auto-compensation 계산. size 안 넘기면 SVG 24px 기준으로 보정 후 CSS로 축소 → 시각적 stroke가 절반이 됨
- **color-scheme 미설정** — `light-dark()` CSS 함수는 클래스 기반 테마에 자동 반응하지 않음. `.dark { color-scheme: dark }`를 명시해야 glass 다크모드 색상이 올바르게 적용됨
