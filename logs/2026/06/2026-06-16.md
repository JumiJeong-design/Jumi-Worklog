## Decisions

- Glass 표준: `tone="ios"` + `displace={6}` + `backgroundOpacity={0.3}` — ios tone 담백, displace로 backdrop blur, opacity로 배경 반투명
- `light-dark()` CSS 함수는 `color-scheme` 속성 기준 — `.dark` 클래스만으론 부족, `styles.css`에 명시 필요
- Storybook light 선택 시 `.light` 클래스 명시 추가 필요 (기본값이 dark)

## Attempts / Traps

- **GlassSurface className vs contentClassName** — `className`은 outer container. flex 레이아웃은 반드시 `contentClassName`에
- **ios tone ≠ 블러 없음** — chromatic aberration만 줄임. 블러는 `displace` prop 별도 설정 필요. 기본값 0
- **Checkbox size prop 누락** — size 없으면 CSS 축소 시 stroke 절반
- **color-scheme 미설정** — `.dark { color-scheme: dark }` 없으면 glass 다크모드 색상 오류
- **worklog 갱신 누락** — PR 머지·Chromatic 업로드가 실제로는 완료됐는데 worklog/CONTEXT.md/prism plan 문서에는 "남은 항목"으로 그대로 남아있었음. 작업 완료 직후 관련 기록을 갱신하지 않으면 다음 세션이 잘못된 상태를 신뢰하게 됨.
