### 가입/로그인 플로우 텍스트 초안

- 한국 첫 화면은 `카카오로 시작하기`를 1순위로 두고, 같은 화면의 보조 수단으로 `전화번호로 시작하기`를 둔다.
- 일본 첫 화면은 `LINE으로 시작하기`를 1순위로 둔다. `Google로 계속하기`, `Apple로 계속하기`는 보조 수단으로 노출한다.
- `다른 방법`을 열면 지역별 첫 화면에 숨긴 수단까지 포함해 전체 지원 수단을 보여준다. 전체 목록 후보는 카카오, LINE, Google, Apple, 전화번호다.
- 전화번호 인증은 국가·통신/SMS 대행사·개인정보 처리/약관 조건 확인이 필요한 항목으로 분리한다. 특히 외국사 서비스에서 전화번호를 기본 수단으로 전면 배치할 수 있는지, 어떤 고지/동의 문구가 필요한지는 Figma 제작 전에 별도 확인한다.
- Figma 화면 제작은 주미님 결정 대기 상태로 둔다. 오늘 정리 범위는 텍스트 기준 초안까지다.

### locale fixture ko/en/ja QA 범위

- QA 범위는 fixture 코드 수정이 아니라 확인 축 정의까지다.
- ko는 기준 언어로 누락 키, 어색한 용어, 버튼/상태 라벨의 의미 일관성을 본다.
- en은 한국어보다 길어지는 CTA·상태 문구·설명 문장이 레이아웃을 밀지 않는지 본다.
- ja는 일본어 줄바꿈, 긴 고유명사/상태 라벨, 문장 톤이 한 화면에서 읽히는지 본다.
- 공통 축은 light/dark, mobile 393, web, long content, empty/error/fallback 상태다. 실제 fixture 데이터 수정과 내부 QA 실행은 별도 작업으로 보류한다.

### 요청 범위

```text
Page design_chart 반복 가설 카드/칩을 공통 컴포넌트화할지 판단하고, 차트 디자인 정합도 함께 진행한다.
```

### 완료

- `Page design_chart`와 `Opinion Viz (ideation)`를 기준으로 4개 차트 구조를 감사했다. 신규 토큰 없이 기존 foundation gradient, 색, 텍스트 스타일을 재사용하는 기준으로 정리했다.
- `ModelChip` 로컬 컴포넌트를 만들고 일본노후 화면의 손코딩 모델 pill 79개를 인스턴스로 교체했다. 가설 카드 자체는 별도 컴포넌트로 만들지 않고 칩 인스턴스 조립 프레임으로 유지했다.
- 도넛은 `ConsensusDonut`을 정본으로 확정했다. 분포 샘플 4종을 만들고, test 화면의 raw 무지개 ring을 `ConsensusDonut` 인스턴스로 교체했으며 중앙 라벨 override 버그를 수정했다.
- 투표막대는 실제 렌더 기준으로 드리프트가 없음을 확인했다. 반복 원자인 `LegendItem`을 컴포넌트화하고 범례 15개를 인스턴스로 교체했다.
- 생성 컴포넌트와 갤러리 scaffold의 하드코딩을 교정했다. `ModelChip`은 `caption/2`, `LegendItem`은 `body/sm-r` 텍스트 스타일에 연결했고, 도넛 샘플 갤러리도 semantic surface/text 변수로 바인딩했다.
- 도넛 arc는 기존 `gradient/blue`, `gradient/purple`, `gradient/cyan`, `gradient/pink`, `gradient/orange` 스타일에 연결했다. 4개 화면 재감사 결과 unbound solid 0, unstyled text 0, gradient-no-style 0으로 정리됐다.
- 아이데이션 페이지 토큰/스타일 전수 감사에서 미바인딩 29건을 3건으로 줄였다. 남은 3건은 PickBubble 아바타 이니셜 글리프라 의도적으로 유지했다. Group 4 teal은 주미님 선택대로 `cyan/500`에 바인딩했다.
- `Message Bubble/ModelLabel`을 `Model` variant 5종(Claude, GPT, Gemini, Grok, Perplexity) 컴포넌트 세트로 정리했다.
- 해외 여행지 화면의 투표 결과/추천 질문 영역은 `QuestionItem`, `VoteBar`, `RecommendedQuestions`, `VoteResult` Figma master로 올리고 실제 프레임을 인스턴스로 치환했다. 패키지 포팅과 Storybook 승격은 ideation 승격 확정 뒤로 둔다.
