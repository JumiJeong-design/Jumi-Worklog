## Socra Prism — Chat History Panel 다국어 동기화

### 사용자 요청

```
1. 피그마에 한글 버전 컴포넌트 히스토리쪽 문구랑 디자인 수정했는데, 이게 다른 언어 디자인에도 반영되면 좋겠어. 다른 언어들 화면에도 반영되도록 스트링이 토큰화되어서 변화되게 해야겠지?
2. 그리고 지금 피그마 기준으로 깃에 컴포넌트 일치 안된거 일치 시키면 좋겠어. 피그마 -> 깃에 일치 -> 스토리북 반영
```

### 작업

- Figma `Socra Design system test`에서 `Chat History Panel` 현재 노드(`1349:1550`)와 `History Item`(`57:46`)를 read-only 감사했다.
- `packages/prism`에 `ChatHistoryPanel` 컴포넌트를 추가했다.
  - `chatHistoryPanelStringTokens.ko/en/ja`
  - `locale?: "ko" | "en" | "ja"`
  - `copy`, `items`, `accountInitials` override
- `HistoryItem` 기본 시각을 피그마 기준으로 동기화했다.
  - 75/51px 높이
  - 12px padding
  - default trailing icon 숨김
  - selected 상태는 pressed surface
- `home`, `plus`, `panel-left` 아이콘을 `PrismIcon`에 추가했다.
- EN/JP mobile history와 EN/JP web home/chat Figma 화면의 텍스트 override를 토큰 기준으로 맞췄다.
