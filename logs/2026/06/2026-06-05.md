### 결정사항

- category color set은 현재 active foundation에서 제외한다. taxonomy와 실제 화면 사용처가 확정되면 최소 semantic set으로 재검토한다.
- dark mode opacity는 `black alpha`와 `white alpha`를 1:1로 뒤집는 방식으로 운영하지 않는다.
- opacity가 필요한 경우에도 `overlay/scrim`, `state/disabled`, `state/pressed`, `focus`, `shadow/dark/*`처럼 role semantic token으로 분리한다.
- Storybook/package code 변경은 명시 승인 전에는 진행하지 않는다. 오늘 push는 Figma evidence/docs 중심이다.
- Markdown table은 header row와 body cell이 같은 스타일로 뭉개지지 않게 head, column, cell 역할을 분리한다.
