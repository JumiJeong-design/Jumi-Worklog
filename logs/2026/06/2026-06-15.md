### Stroke width 후속

- Foundation 기준을 `1px` border, `1.5px` small icon thin, `1.8px` 기본 icon/control, `2.2px` strong mark로 정리했다.
- `design-system/foundation/stroke-width.md`, `design-system/rules.md`, `design-system/components.md`, `design-system/tokens/tokens.json`, `packages/prism/token-contract.md`에 기준을 반영했다.
- `PrismIcon` 기본 stroke를 `1.8` 상수로 유지하고, 10~16px small icon에는 `1.5` thin 값을 명시했다.
- Checkbox/Radio outline은 `--stroke-width-control` 1.8px 기준으로 올렸다.
- Checkbox checked mark는 sm/md 모두 `--stroke-width-icon-strong` 2.2px로 보정했다.
- Toast 타입 배지 내부 아이콘은 2.2px로 올리고, dismiss icon은 기본 1.8px로 유지했다.
- Chip removable close button은 Figma `201:166` 기준 sm 14x14 / icon 10px, md 18x18 / icon 12px로 분리하고 stroke 1.5px를 유지했다.
- Chat Input Bar 기본 glass border는 `--stroke-width-border` 1px 기준으로 정리했다.
- Chat Input Bar attachment thumbnail row는 glass surface 내부에서 crop되도록 `overflow-hidden` 범위를 보정했다. XBtn은 Figma `photo/XBtn` (`351:544` / `351:534`) 기준 18x18, radius 12px, close icon 12px/1.5px로 맞췄다.
- GlassSurface에 `tone="ios"` opt-in을 추가하고 Header Nav Bar icon slot, Chat Input Bar, Toast에 적용했다. RGB displacement를 낮춰 oil-slick처럼 보이는 반짝임을 줄였다.
- `--stroke-width-*` CSS 변수가 public manifest에 빠지지 않도록 token build 산출물도 보정했다.
- 검증: `pnpm check` 통과. `pnpm visual`은 Storybook build까지 통과했고 Chromatic 업로드는 `CHROMATIC_PROJECT_TOKEN` 누락으로 실패.
