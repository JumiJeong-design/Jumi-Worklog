### 요청 범위

### 검토 결론 (루프화 후보)

- prism은 검증·시각회귀가 이미 CI(`release.yml`)로 루프화돼 있고, 피그마 시각 변경은 승인 게이트로 사람이 잡는 구조 = 글이 말한 "잡기 싼 층은 자동, 비싼 taste 층은 사람"에 이미 부합.

### 완료 (riiid/prism, 브랜치 `plan/parallel-codex`, 로컬 미커밋)

## 21st.dev 리퀴드 글래스 버튼 vs 기존 GlassSurface 비교 (검토만, 코드 변경 0)

### 요청 범위

### 결론 — import 금지, 참고 포인트 1개만

- **결정적 리스크 = 우리가 이미 푼 문제를 되돌림.** 21st 코어는 `backdrop-filter: url(#svg)` = **Chromium 전용** → Safari/Firefox에서 글래스 깨짐. 우리 GlassSurface가 Figma iOS 글래스에서 의도적으로 갈라진 이유가 정확히 이거(`supportsSvgFilters()` 분기 + fallback blur). 통째 도입은 **회귀**, 특히 모바일/일본 2030 = iOS Safari 비중 큼.
- **왜곡 품질은 우리가 우위** — 우리 = RGB 3채널 `feDisplacementMap` + `feColorMatrix` + `feBlend screen` = 색수차(chromatic aberration)까지; 21st = 변위맵 1개.
- **텍스트 고스팅도 우리는 구조로 해결** — content를 필터 밖 `__content` div로 분리 + `backdrop-filter`는 뒤만 흐림. 21st가 "z-index lens로 고스팅 제로"를 세일즈 포인트로 내세우는 부분.
- **유일하게 참고할 점** = framer-motion 커서 추적 + 스프링 scale로 렌즈가 마우스 따라 출렁이는 "살아있는" 인터랙션. 단 **데스크톱 전용**(터치엔 포인터 없음).
