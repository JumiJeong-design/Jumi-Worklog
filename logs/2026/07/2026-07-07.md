### 함정 모음

- **Workflow `args` 문자열 도착** — `args`를 JSON object로 넘겨도 스크립트 전역 `args`엔 **문자열**로 도착해 `const {inventory}=args`가 undefined → `inventory.join` 즉시 실패(atomic, agent 0개 실행). 방어적 `const a = typeof args==='string'?JSON.parse(args):args`로 해결. 대용량 데이터는 args로 분리하되 스크립트에서 파싱 방어 필수.
- **`use_figma` 폰트 선로드** — 텍스트 든 노드를 clone/detach/appendChild(reparent)할 때 `Cannot write to node with unloaded font "Pretendard Regular"`. 스크립트는 atomic이라 실패 시 무변경 → `loadFontAsync(Regular/Medium)` 선행 후 재시도 안전. (문자열 편집뿐 아니라 reparent에도 적용.)
- **컴포넌트 세트 자동 확장 안 됨** — 자식 variant를 추가/이동해도 세트 프레임이 자동으로 안 커져 밖으로 클립됨(Mode Toggle 세트, ChatInputBar 세트 둘 다). `set.resize(w,h)`로 명시적 확장 필요.
- **blind sweep 금지 — 정확 매칭만** — 1line radius 재바인딩 시 image-attached는 의도적 `radius/4xl`(28)이라, `spacing/16`(32)에 바인딩된 것만 교체하는 self-guard로 자동 제외. count 기반 일괄 변경이었으면 28을 오염시켰을 것.
- **이 harness엔 `Explore` 에이전트 없음** — 서브에이전트는 `general-purpose`로. (첫 시도 `Explore` 호출이 "No such tool"로 실패.)

### 회고 및 인사이트

#### AI 도구 활용

- **시안=목업으로 승인 게이트** — 신규 Mode Toggle을 세트에 바로 넣지 않고, 스크래치에 (a)단독 토글 (b)2line 인컨텍스트 (c)1line 인컨텍스트 목업을 만들어 스크린샷으로 형태·위치를 합의한 뒤 컴포넌트화. 정적 시각 결정은 "말로 제안"보다 "목업 보여주기"가 왕복을 줄임.
- **갭 감사 = 멀티에이전트 fan-out** — 기획서 10개 화면을 병렬 감사(각 에이전트에 Figma 79컴포넌트 인벤토리 + 스펙 요구사항 주입, 패키지 코드까지 grep) → 통합 에이전트가 중복제거·우선순위. 11 에이전트·550k 토큰. 근거 있는 판정("MultiAgentComparison은 ChartBlock status=hypothesis table fallback", "Toggle.tsx role=switch", "PromptPill grep=0")까지 나옴.
- **Figma write 전 read-only 정밀 감사** — 노드별 `boundVariables` 실측으로 하드코딩 vs 바인딩을 가른 뒤에만 편집. 인스턴스 blast radius(11개 전부 손상 0)도 이름 변경 전 `component.instances`로 사전 확인.

#### 설계 결정

- **radius/5xl(=32) 신설** — radius 램프 `3xl 24·4xl 28` 다음. 그동안 32 라디우스를 `spacing/16`(스페이싱 토큰)에 바인딩하던 드리프트를 교정(1line·2line 전 InputContainer 재바인딩, 픽셀 0). "없으면 변수 먼저 추가" 원칙.
- **SendActive 제거는 코드 무변경** — 활성 전송은 코드에서 `state`(filled/image-attached) 파생 내부변수라 Figma `SendActive` 축은 vestigial. 축 제거·`Guide text` True→true 통일 모두 non-breaking(문서 동기화 + patch changeset만).
- **Mode Toggle = 2-state 세그먼트** — 기획서 §4.1(현재 모드 라벨 + 전환 애니메이션). Chat은 자동 트리거(§4.2)라 토글 옵션 아님 → 이진. 형태=iOS 세그먼트(인셋 트랙 `surface/Inset` + 흰 thumb `surface/Raised`, 주미님 확정). 기존 `Toggle`(on/off 스위치)은 오답 패턴.
- **홈·챗 모두 2line 통일** — 토글이 항상 하단 액션 행(`[📎][Quick|Deep] … [↑]`)에 위치. 1line 한 줄엔 자리가 없다는 점이 2line의 존재 이유. 1line은 레거시/컴팩트로 존치.
- **갭 감사 통찰** — 골격(Nav·오버레이·MessageBubble·마크다운·다크·i18n 렌더)은 탄탄. **최대 구멍 = 결과 화면 데이터 시각화**(가중치 그래프·공통/고유 리포트·지지율 칩·진행 스텝퍼) = 소크라 차별점이 정확히 미설계.

## ChatInputBar 2line 확장 컴포저 — 정합 + 리스크·프로퍼티 정리

주미님이 `Chat Input Bar`(`29:2`)에 직접 추가한 홈용 `Type=2line`(default `3397:1405`·filled `3397:1417`, 텍스트 행 위 + 첨부/전송 버튼 행 아래). 감사 후 정합·리스크·프로퍼티를 순차 처리(전부 픽셀 변화 0, 스크린샷 검증).

- **하드코딩 정합** — TextArea padding 12px 4면 미바인딩 → 기존 `spacing/6`(=12) 바인딩(신설 아님, 포팅). 버튼 행 `itemSpacing=500` 꼼수 → `SPACE_BETWEEN`(폭 변화에 견고). TextArea 세로 sizing default(FIXED 78)/filled(HUG) 불일치 → `HUG`+`minHeight 78` 통일.
- **Risk1 — radius/32 토큰 부재** — `radius/5xl`(=32, CORNER_RADIUS 스코프) 신설(`3406:2`). 2line 컨테이너 + 1line 7개 InputContainer를 `spacing/16`→`radius/5xl` 재바인딩(image-attached의 의도적 28은 정확매칭 self-guard로 자동 제외).
- **Risk3 — primitive 색 드리프트** — placeholder/저강조 텍스트를 `neutral/400`(primitive)→`semantic/text-tertiary`(→neutral/400 앨리어스, 픽셀 동일) 재바인딩. 2line + 1line 6개 텍스트.
- **프로퍼티 정리** — `SendActive`(옵션 `false` 하나뿐 죽은 축) 제거, `Guide text` 값 `True`→`true` 통일. 10 variant 재명명, 인스턴스 11개(전부 1line default/filled) 손상 0. 최종 프로퍼티 = `Type[2line,1line]·State[7]·Guide text[false,true]`.
- **코드·문서** — 코드 무변경(SendActive=state 파생, guideText=`boolean|string`이라 Figma 리터럴 미사용) → **non-breaking** 확인(서브에이전트 전수 조사). `component-contracts/chat-input-bar.md`·`design-system/components/chat-input-bar.md` 동기화 + patch changeset 추가.
