## 🔡 타이포 변수↔스타일 sync 감사 + 행간/자간 단위 결정

"폰트–변수–Figma 스타일 sync가 잘 되는지(변수 바꾸면 스타일 따라오는지)" 감사에 이어, 행간/자간 단위 모델을 확정. Figma write는 read-only 실측 후 게이트대로, 결정은 워크플로 적대적 3관점 검증으로 확인. plan-15 정본.

### 요청

```
prism docs/plans/15 읽고 어제 이어서. 오늘은 lineHeight/letterSpacing 단위 모델:
```

### 검증 — 행간/자간 변수 바인딩 (결론: 불가)

- 비파괴 `use_figma`(임시 노드/스크래치 스타일 생성→측정→삭제, 실제 82스타일·변수 무변경)로 전수 측정:
  - 노드 lineHeight `{PERCENT,160}` → 바인딩 후 **`{PIXELS,1.6}`** (160%가 1.6px로 붕괴)
  - 노드 letterSpacing 비영값 `{PERCENT,2}` → **`{PIXELS,2}`** (비영값 확증)
  - **공유 TextStyle** lineHeight도 `{PERCENT,160}` → **`{PIXELS,1.6}`** (스타일 경로 동일)
- 변수는 정상(FLOAT·scope 정확) → 설정오류 아닌 **플랫폼 제약**. Figma 변수 타입에 percent/multiplier 없음, AUTO=값없음, 모드=변수당 스칼라 1개.

### 결정 — 미바인딩 유지(Option B) 확정

- 워크플로 적대적 3관점(Figma 플랫폼 / DS 아키텍처 / 코드·i18n) 전원 B 유지·high. Option A(px 전환)는 변수 ~4.2× 폭증 + 반올림 px 충돌 + plan-14(반응형) 정면충돌 + 코드 unitless 드리프트 + 파괴적 롤백이라 열등.
- **주미님 실제 기준 = 변수↔스타일 sync**로 재판단해도 결론 동일: 역방향(스타일→변수)은 피그마에 전 속성 미지원, 정방향(변수→스타일)은 크기·폰트만 확보(줄/자간은 px강제로 불가), A는 크기↔행간 sync를 새로 깨서 **sync 기준으로도 열등**.

### 함정 / 인사이트

- **Figma 변수는 단위(%)를 못 담는다** — 길이형 텍스트 속성(fontSize/lineHeight/letterSpacing/paragraphSpacing)에 FLOAT 바인딩 시 무조건 px. 절대값(px 크기·문자열 폰트)만 무손실 sync, 비율(행간 배수·자간 %)은 불가. "FLOAT는 항상 px"는 과장 — opacity/rotation/weight는 예외.
- **Figma 변수 이름에 소수점(`.`) 금지** — probe로 확인(`1.3`·`-1.2` 실패, `130`·`-2`·`-120` 성공) → ×100 네이밍 채택.
